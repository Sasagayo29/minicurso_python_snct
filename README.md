Repositório com os materiais, códigos e bases de dados utilizados no minicurso **"Mulheres na Tecnologia: Primeiros Passos com Python para Automação e Análise de Dados"**, ministrado durante a 23ª Semana Nacional de Ciência e Tecnologia (SNCT) no IFTM - Campus Paracatu.

## 🎯 Objetivo
Desmistificar a programação e incentivar a inserção feminina na área de Tecnologia da Informação, utilizando a linguagem Python para demonstrar como automatizar tarefas e analisar dados de forma prática, rápida e acessível.

## 📂 O que você vai encontrar aqui?
* **`mercado_tecnologia.csv`**: Base de dados fictícia com salários e vagas na área de TI, usada para a aula prática de Pandas.
* **`quiz_expandido.py`**: Um joguinho de perguntas e respostas completo sobre pioneiras da computação (excelente para treinar lógica, `if/else` e `for`).
* **`analise_local.py`**: Exemplo de código de como ler uma planilha do seu próprio computador usando Python.

## 🚀 Como utilizar os códigos
Não é necessário instalar nada no seu computador! Nós utilizamos o **Google Colab**.
1. Acesse o [Google Colab](https://colab.research.google.com/).
2. Crie um "Novo Notebook".
3. Copie o código dos arquivos `.py` deste repositório e cole nas células do seu Colab.
4. Aperte `Shift + Enter` (ou clique no botão de Play) para rodar o código.
